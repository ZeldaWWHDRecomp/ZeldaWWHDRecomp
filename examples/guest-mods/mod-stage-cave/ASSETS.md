# Original cave chamber assets

`assets/room.glb` (the chamber's floor, walls, ceiling, pillars and ledge) was generated by
`assets/make_room.py` for this example, MPL-2.0; the script reproduces it without external assets. The
model carries no texture: the game draws it with materials of the lava cave's first room, taken from the
player's own game files when the stage is built. No game models, textures, collision files or archives
are included.
