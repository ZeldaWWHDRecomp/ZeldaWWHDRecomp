# Original game-materials island assets

The models were generated by `assets/make_models.py` for this example, MPL-2.0. The script reproduces
`assets/rock.glb`, `assets/rock-far.glb` and `assets/lookout.glb` using only Python's standard library.

No game models, textures, collision files or archives are included. The materials named `Txe_gake_v` (rock),
`Txe_hai_v` (ash) and `Txe_ita_v` (wooden planks) have no texture: they are names of Dragon Roost Island's
materials (`{"stage": "sea", "room": 13}`), which the port draws from the player's own game files
(docs/world-objects.md, "Game materials"). The only texture in the package is the lookout roof's red cloth,
128 × 128, drawn by `make_models.py`.

| Model | Triangles | Materials |
| --- | --- | --- |
| `rock` | 262 visible, collision from `model_col` (stone, sand, wood) | rock, ash, planks (game) |
| `rock-far` | 108, its distant model | rock, ash (game) |
| `lookout` | 80 | rock, planks (game), cloth (its own texture) |

The island stands at (214000, 0, -186000) in sea room 13, Dragon Roost Island's square, about 18,000 units
south-east of Dragon Roost. The lookout stands on its ash top; both are the composition `rock-isle`.
