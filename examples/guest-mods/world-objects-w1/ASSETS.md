# Original island assets

The hill, beach, wooden pier and checker texture were generated by
`assets/make_fixtures.py` for this example, MPL-2.0. `assets/make_fixtures.py` reproduces `assets/island.glb` without
external assets. The visible mesh uses one embedded texture. A separate
`island_col` mesh supplies sand, grass and wood collision through material names.

The coast extends below the sea for the native ship collision samples. The
example is placed in an empty part of sea room 12, east of Windfall. No game
models, textures, collision files or compiled archives are included.
