# Original floating assets

The raft, buoy, flotsam and checker textures are generated by
`assets/make_fixtures.py` for this example, MPL-2.0. The script reproduces all
three `.glb` files using only the Python standard library.

Each file contains one visible textured mesh and its authored `_col` mesh.
The raft and flotsam keep their thin wooden ground surfaces. Their additional
`col_objects` side walls provide collision for object-class queries, including
the ship. Link, the camera, arrows, bombs, boomerangs and rope pass through those
additional walls. The walls have no top or bottom ground faces. The buoy has
an ordinary tall metal collision hull.

No game models, textures, collision files or compiled archives are included.
