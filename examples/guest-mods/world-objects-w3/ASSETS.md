# Original interactive tower

Assets generated by `make_fixtures.py` for this example, MPL-2.0.

`assets/make_fixtures.py` reproduces `assets/tower.glb` using only Python's
standard library. All geometry and the embedded opaque checker atlas are
original. No game models, textures, collision files or archives are included.

The file contains one textured visible primitive and a separate `tower_col`
mesh. Collision materials are `col_stone`, `col_wood`, `col_climb` and
`col_hookshot`. Climb and hookshot surfaces use native interaction attributes.

Dimensions below are game units; the GLB stores meters (100 game units per
meter). Intended world origin: (75000, 500, -201500), sea room 12.

- Base: x/z +/-800, top y=0, bottom y=-1000. It supplies a 500-unit walkway
  around the tower and a deep ship-blocking hull.
- Tower: x/z +/-300, top y=1200. The full top is walkable, with no parapet.
- Climb face: front z=-300, full width and height. Its normal points toward
  negative Z. The upper ledge meets the stone roof exactly.
- Hookshot patch: right wall x=300..306, y=800..1000, z +/-80. Its outer
  face points toward positive X; approach from the right side.
- Wood grapple visual: x +/-200, y=770..830, z=-355..-305. Anchor center is
  (0,800,-330), near the requested front-wall point. Climb at x +/-250 to
  avoid the crossbeam. The grapple point uses yaw 90 degrees
  for an approach from negative Z (perpendicular to the beam).

Suggested proof setup: use the front deck to approach the climb lanes, the right
walkway to aim at the hookshot patch, and an unobstructed frontward position
for grapple aiming. A separate anchor proxy is required for the grapple;
collision materials alone do not register rope targets. The native targeting rules apply, including the post orientation, range and
height tolerance.
