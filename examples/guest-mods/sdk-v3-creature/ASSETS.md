# Original coral wanderer

`assets/creature.glb` is generated by `assets/make_creature.py`. The original
geometric mesh, three-bone rig, painted PNG and idle/walk/talk/wave animation
clips are by Lukas S and licensed MPL-2.0. This coral-coloured variant adapts the
original MPL-2.0 tide sprite source shipped with the Windfall example. The
complete generator is included here; it imports no other package or game data.
Run it with Python 3 to reproduce the GLB. Units are metres, positive Y is up,
and the identity-bind head/body chain faces positive Z.

`mod.c` is original MPL-2.0 example code. It uses static service buffers and a
20-byte actor userdata record, preserves that record on full restore, and binds
the fresh handle in create. It wanders along a bounded current-room path, pauses
for one second with the named `wave` clip after an informational native hit,
and resumes. Hits change no retail combat or save data. Draw has no callback.

The scene's `coral` cue streams an original 200 Hz triangle wave at low amplitude
through the public 48 kHz mono PCM service. It uses fixed storage, handles partial
submissions and unavailable/stale streams, and reopens after audio epoch changes.
STOP/RESTORE closes its own stream and restores prior silence; it never changes
the game's music. Only zero fade is supported. Callback logs remain observable
when shared output is muted. Audio queues are not part of full save states.

Build `mod.c` as a PowerPC relocatable `mod.elf` using the guest SDK toolchain
before packaging this example. Compiled guest output is deliberately not stored
in this source example. It requires Story Notebook and a code-mod-enabled build.
The example is experimental; native hit, motion, scene and audio acceptance must
be checked on the build being distributed. No game models, textures, shaders,
materials, sounds or derived templates are included.

For a Clang installation with the PowerPC target and LLVM LLD, run from this
package directory (set `SDK` to the guest SDK include directory):

```sh
clang --target=powerpc-unknown-eabi -mcpu=750 -O2 -ffreestanding -fno-builtin -nostdlib -fno-jump-tables -ffunction-sections -fdata-sections -I"$SDK" -c mod.c -o /tmp/creature.o
ld.lld -m elf32ppc -r /tmp/creature.o -o mod.elf
```
