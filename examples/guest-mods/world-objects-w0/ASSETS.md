# Original proof assets

The platform and ramp, buoy, raft, and their checker textures were generated by
`make_fixtures.py` for this example, MPL-2.0.
`assets/make_fixtures.py` reproduces all three `.glb` files without external assets.
No game models, textures, collision files or compiled archives are included.

The render models use metres. Their collision is independently handmade in the
W0 runtime fixture; the model converter is used only for rendering.
