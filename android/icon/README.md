# App icon

`app_icon_1024.png`: the app's icon, a sailing boat on the sea. Original artwork by the
ZeldaWWHDRecomp project lead, published under the repository's licence. It contains no material from
the game.

Made from it: `app/src/main/res/mipmap-*/ic_launcher.png` (rounded squares for launchers without adaptive
icons), `app/src/main/res/drawable-nodpi/ic_launcher_art.png` and `mipmap-anydpi-v26/ic_launcher.xml`
(the adaptive icon on Android 8+). The Linux AppImage uses the 192 px launcher icon. The iPhone GamePad
app's default icon is this file too (`ios/WWHDGamePad/Assets.xcassets/AppIcon.appiconset/AppIcon.png`
is a link to it).
